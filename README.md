# ox-vscode

Official Visual Studio Code extension with Ox language-server, formatter, testing, and debugging integration.

## Status

Alpha integration: syntax highlighting plus the `ox lsp` server for diagnostics,
formatting, completion, hover, and go-to-definition. Install the Ox CLI on `PATH`
before launching VS Code.

## Scope

- Keep this repository focused on the responsibility above.
- Track compatibility against `ox-spec` and conformance through `ox-tests`.
- Document supported versions, security boundaries, and release policy before the first public release.

## Development

Tooling and implementation commands will be added when this component enters active development.
